# CineFace AI Studio 🎬

> Production-grade web application for photorealistic AI video creation, digital avatar synthesis, script generation, and viral content reverse-engineering.

---

## 🌟 Key Capabilities

1. **Photorealistic AI Presenters**:
   - Authorized Photo Likeness upload with explicit biometric consent safeguards.
   - 9 high-fidelity calibrated presets (Entrepreneurs, Teachers, Presenters, Storytellers, Monks, etc.).
   - Custom fictional persona generation.
2. **AI Spoken Script Engine**:
   - Powered server-side by Google Gemini 3.8 Flash SDK.
   - Live spoken duration and word-count estimation (~135 wpm).
   - Instant AI script generation and iterative refinement (Hooks, Pacing, Spoken Naturalness, Conversion).
3. **Viral Reference Video Analyzer**:
   - Deconstructs high-performing reference videos: Hook mechanisms, narrative structure, pacing, curiosity loops, emotional approach, and CTA frameworks.
   - **100% Original Adaptation**: Formulates a completely new script tailored to the user's own product or e-book without copying or plagiarism.
   - Seamless one-click transfer into the creation studio.
4. **Multilingual Speech & Swahili Support**:
   - Studio voices with granular speech rate ($0.75\times$ to $1.5\times$) and pitch modulation.
   - Authentic East African Swahili (`sw-KE` Nairobi Standard and Coastal accents) along with English, Spanish, and French.
5. **Clean Provider / API Abstraction**:
   - Strictly decoupled frontend from underlying video generation engines.
   - Supports HeyGen, Runway Gen-3, Google Veo, and a Mock Development Sandbox for offline testing.
   - Never exposes API keys or secrets to the client browser.
6. **No-Database Ephemeral Privacy**:
   - Zero permanent data retention in v1.0. No accounts or credit cards required.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide Icons, Framer Motion
- **Backend**: Node.js, Express, Vite middleware mode (`server.ts`)
- **AI Engine**: `@google/genai` (Gemini 3.8 Flash for script generation and structural content analysis)
- **Deployment**: Vercel & Node.js / Docker / Cloud Run compatible

## 💻 2. How to Run Locally

Start the full-stack server (Express backend + Vite client middleware on port 3000):

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

## ⚙️ 3. How to Configure Environment Variables

Create a `.env` file in the root directory (based on `.env.example`):

```bash
# GEMINI_API_KEY: Required for AI script generation & reference video analysis
GEMINI_API_KEY="your-gemini-api-key"

# Active Video Generator Engine ("mock" | "heygen" | "runway" | "veo")
AI_VIDEO_PROVIDER="mock"

# External Video Provider Keys (Server-side only):
HEYGEN_API_KEY="your-heygen-api-key"
RUNWAY_API_KEY="your-runway-api-key"

# Port (Defaults to 3000)
PORT=3000
```

## 🧩 4. How the Video Provider Abstraction Works

All video rendering operations flow through the `IVideoGenerationProvider` interface located in `/server/videoProviders/types.ts`:

```typescript
export interface IVideoGenerationProvider {
  id: string;
  name: string;
  description: string;
  isConfigured(): boolean;
  supportedFeatures: string[];
  generateVideo(config: VideoGenerationConfig): Promise<{ jobId: string; status: JobPhase; message?: string }>;
  getStatus(jobId: string): Promise<ProviderJobStatus>;
  cancelJob(jobId: string): Promise<boolean>;
}
```

The `VideoProviderManager` (`/server/videoProviders/index.ts`) detects configured credentials and dispatches requests to the active provider. You can inspect or toggle active providers directly from the UI by clicking the **Provider Badge** in the top navigation bar.

## 🧪 5. Mock / Demo Mode vs Real Generation

- When no external video provider API key is set, the application automatically uses the **Mock Development Sandbox** (`server/videoProviders/mockProvider.ts`).
- **Full Honesty**: The UI explicitly labels sandbox generations with `Sandbox Mode (Simulation)`. It never falsely claims that a mock output was generated by a real external service.
- The sandbox simulates the realistic multi-stage rendering pipeline:
  1. `Preparing script & phoneme tokens...`
  2. `Synthesizing voice & acoustic cadence...`
  3. `Synthesizing facial topology & eye contact...`
  4. `Rendering lip synchronization & frames...`
  5. `Finalizing high-resolution output...`
- It provides a full interactive video preview player, dimension calculations, download buttons, and job cancellation so the entire user flow can be rigorously tested.

## 🔌 6. How to Connect a Real Video-Generation Provider

1. **HeyGen API**:
   - Obtain an API key from [HeyGen](https://heygen.com).
   - Set in `.env`:
     ```bash
     AI_VIDEO_PROVIDER="heygen"
     HEYGEN_API_KEY="your-key-here"
     ```
   - Restart the server. HeyGen will render photorealistic talking photos with full lip synchronization.
2. **Runway Gen-3 API**:
   - Obtain an API key from Runway.
   - Set `RUNWAY_API_KEY="your-key"` and `AI_VIDEO_PROVIDER="runway"`.
3. **Google Veo**:
   - Ensure your `GEMINI_API_KEY` has access to Veo models (`veo-3.1-lite-generate-preview`).
   - Set `AI_VIDEO_PROVIDER="veo"`.

## ☁️ 7. How to Deploy to Vercel

1. Push your repository to GitHub.
2. Connect your repo in the [Vercel Dashboard](https://vercel.com).
3. Under **Project Settings > Environment Variables**, add:
   - `GEMINI_API_KEY`
   - `AI_VIDEO_PROVIDER` (e.g. `mock` or `heygen`)
   - `HEYGEN_API_KEY` (if using HeyGen)
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy! Vercel handles frontend asset serving and API route orchestration.

## 🛡️ Legal Safeguards & Likeness Ethics

- **Mandatory Consent**: Users must explicitly confirm ownership or authorization when uploading a real person's photograph.
- **No Unauthorized Impersonation**: Built-in safeguards prohibit non-consensual likeness manipulation and deceptive voice cloning.
- **Zero-Database Privacy**: Media and scripts are processed ephemerally in server memory during the active generation session and not stored in any permanent database.
